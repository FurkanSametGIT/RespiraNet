# Tıklanabilir 6 ekranlı HTML mockup

`index.html` dosyasını Chrome / Firefox ile açın. İnternet, veri tabanı, API bağlantısı gerekmez. İçindeki tüm olasılıklar / tarih ve kayıt satırları **temsili**, ölçülmüş model çıktısı değildir.

Akışlar: Giriş → Ana panel → Ses yükleme → Analiz sonucu → Geçmiş → Model karşılaştırma. Yan menüyle tüm ekranlara geçilebilir. Harici WAV seçiminde dosya seçilmediğinde / WAV değilse / boş dosyaysa / 20MB üzerindeyse hata bildirimi görünür; geçerli harici dosyada yalnız kalite ekranı açılır. Gerçek ses çözümleme, gerçek hesap açma veya API erişimi **yoktur**.
