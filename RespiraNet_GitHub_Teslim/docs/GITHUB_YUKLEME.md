# GitHub teslimi — adım adım

Bu paket henüz kullanıcı hesabındaki gerçek bir GitHub reposuna gönderilmedi. Öğretim elemanının istediği teslim için:

1. GitHub hesabında yeni bir `RespiraNet` reposu açın. Gerekli erişim için öğretim elemanı ve ekip arkadaşınızı collaborator olarak ekleyin. Üniversite teslim şartına göre görünürlüğü belirleyin.
2. `RespiraNet_GitHub_Teslim.zip` dosyasını açın. Çıkan klasörün **içindeki tüm dosyaları** repo köküne yükleyin (README, `.github`, `docs`, `db`, `scripts`, `issues.json`, `issues.csv`). Gizli `.github` klasörünün de gittiğini doğrulayın.
3. Repo ana sayfasında README'deki 6 diyagram bağlantısını kontrol edin. Her diyagramda `.dot` ve `.mmd` kaynakları da olmalıdır.
4. Hafta 2 klasöründeki ER, SQL, veri sözlüğü, teknoloji tablosu ve 6 adet SVG ekranı doğrulayın.
5. Figma'da 6 SVG'yi içe aktarıp butonların `Prototype → On click → Navigate to` bağlantılarını kurun. Paylaşım bağlantısını GitHub README'ye ekleyin.
6. `issues.json` içindeki 21 görevi GitHub Issues'a girin. GitHub CLI kullanacaksanız kök README'deki betik komutunu uygulayın (`--apply` gerçek issue açar).
7. 2. hafta sunumu için üç ana kanıt: diyagramların GitHub linki, Figma Present linki, ER/SQL sözlük ekran görüntüsü.
8. Ekip üyelerinin her ikisinin de katkısı commit geçmişinde görünecek şekilde iş bölümü yapın.

**Dikkat:** Eğitim seslerini, özel kullanıcı bilgilerini, token/parolaları ve model ağırlıklarını bu repo ile paylaşmayın. E0/E1/E2 gerçek ölçüm değerlerini eğitimler tamamlanmadan doldurmayın.
